# Release metadata signed by the Go xtask

TUF metadata generated by the Go release tools (`desktop/internal/xtask`, `./xtask mixer-sign`, and `./xtask mixer-refresh`) for a synthetic packaged mixer release at `targets/mixer-v1.2.3/` (using placeholder ARM64 binaries in the exact layout `./xtask mixer-package` produces). The mixer's verifier has to accept all of these repositories, and the Go signer has to keep emitting identical bytes.

| folder | what |
|---|---|
| `targets/mixer-v1.2.3/` | the payload, its catalog, compatibility, and notices |
| `ed25519/` | fixed Ed25519 keys and expiries, reproducible byte for byte |
| `rsa/` | a `./xtask mixer-keys` root (RSA-3072, RSA-PSS/SHA-256, matching production) |

Each repository contains `root.json` (trusted root), `metadata/` (`mixer-sign`, sequence 1), and `refreshed/` (`mixer-refresh`, sequence 2). All keys here are test-only, untrusted anywhere else, and no private keys are committed.

- Go: `desktop/internal/xtask/release/fixture_test.go` re-signs `ed25519/` byte-for-byte and verifies all four sets with the tough-equivalent loader.
- Rust: `crates/rc2fx-device/tests/xtask_tuf_fixtures.rs` verifies all four using the mixer's in-place update verifier (`sigstore-tuf`).

To regenerate after an intentional change to the signer or payload format, run from `desktop/`:

    RC2FX_WRITE_XTASK_FIXTURES=1 go test ./internal/xtask/release -run TestXtaskFixtures
