# Delta fixtures

Generated by `go generate ./delta` from `desktop/` (`desktop/delta/internal/genfixtures`); don't edit these by hand. Both `desktop/delta` (Go) and `crates/rc2fx-delta/tests/shared_fixtures.rs` (Rust) run against them so the mixer's Rust decoder always accepts what the desktop's Go encoder produces.

- `accept/<case>/delta` decodes into `accept/<case>/envelope` with a size limit equal to the envelope's exact length. Files under `installed/<name>` represent what's already on the mixer; anything absent there is treated as not installed.
- `accept/large-patch` only commits the delta itself. Both test suites reconstruct its envelope and installed files on the fly from the `Large` recipe in `desktop/delta/internal/fixture`, keeping a >1 MiB patch out of git.
- `reject/<case>/delta` must fail to decode. `max` sets the envelope size limit (omit for unlimited). `error` specifies the exact error string both decoders must produce; when omitted, any error is accepted (since the Go and Rust zstd libraries phrase errors differently).
